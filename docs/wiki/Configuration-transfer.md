# 跨 Host 配置导入导出

通过剪贴板把渠道定义和 Host 设置复制到另一台 Host。这是手动同步，不建立 Host 之间的后台连接。

## 导出

1. 打开 Host 插件设置的「导入导出」栏目，先保存或放弃所有栏目的未保存草稿。
2. 按需勾选「导出包含凭据」，默认不勾选。
3. 点击「复制配置」。

不含凭据时，接收端还需填写地址、Token 和目标信息。包含凭据的复制内容是明文，仅粘贴到信任的 Host。浏览器拒绝剪贴板时，允许访问后再次点击复制；手机使用系统粘贴。

## 导入

1. 切换到目标 Host 的同一页面，将 JSON 粘贴到「粘贴配置」。
2. 点「预览导入」，检查渠道、Host 默认、自动恢复、摘要与复核开关、凭据数量。
3. 点「应用导入」。

成功后清空粘贴内容，并显示新增、复用及尚需凭据的渠道数量。导入不自动发送测试通知。

## 合并规则

| 内容                                                  | 行为                                 |
| ----------------------------------------------------- | ------------------------------------ |
| 渠道定义                                              | 与目标 Host 已有渠道合并             |
| 凭据                                                  | 仅在明确包含时迁移                   |
| Host 默认渠道、恢复、复核、通知通用设置、更新检查偏好 | 按导入内容更新                       |
| Schedule / Workspace / Session 绑定                   | 不跨 Host 迁移，保留目标 Host 的绑定 |
| 本机工作区过滤                                        | 不迁移                               |
| 运行记录、预算、待投递通知                            | 不迁移                               |

飞书消息类型会一起导出。含卡片渠道的配置使用剪贴板格式 2，需要 v0.4.0 或更新版本导入；旧版本会拒绝该格式，避免卡片被悄悄改成文本。不含卡片时仍导出格式 1，新版本也能导入旧配置。

完全相同的配置复用已有渠道；消息类型等配置冲突时创建新渠道 ID，并重映射导入的 Host 默认选择。反复导入同一内容不会重复新增。合并后渠道总数不能超过 20。

## 失败处理

预览后目标配置变化，需要重新预览。保存冲突不会覆盖原配置和凭据，粘贴内容保留以便重试。

格式错误时检查是否复制完整 JSON。不能直接导入含本地绑定的普通设置文件。单次导入有约 1 MiB 的字符数量限制。

自动继续只同步 Host 默认参数；工作区、会话的恢复覆盖不导出。导入时保留目标 Host 已有的本地恢复覆盖，继续跟随 Host 的范围会使用导入后的默认值。
