# 宿主能力与限制

这些边界影响实际行为，不属于界面中的可选设置。插件使用 Paseo 的公开插件 SDK；宿主变化可能需要调整适配。

| 能力               | 当前处理                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| 工作区通知设置     | 没有原生 Workspace 设置扩展入口，使用独立工作区面板；从会话通知弹层或命令中心进入                                             |
| 聊天输入区按钮     | 公开 composer pill 接口显示固定铃铛加“通知”短标签，无法注册纯图标按钮                                                         |
| 定时任务列表       | 未提供公开列表 SDK，只读 `$PASEO_HOME/schedules/*.json` 的必要元数据；不读出提示词或执行结果                                  |
| 原子“仍空闲才发送” | SDK 没有原子的条件发送接口；插件在发送前反复核对，极窄时间窗内的人工操作仍可能竞争                                            |
| 重启后的 SDK 连接  | 初始化阶段没有 Paseo API，需要首次回调或 RPC 后核对待恢复任务                                                                 |
| 离线事件重放       | 宿主不向插件重放停用或重载期间错过的事件；只能恢复已经入队的通知                                                              |
| 会话删除           | 公开 SDK 未暴露删除及完整历史目录方法；只读 Host 记录列出会话，通过 CLI 删除确认的完整 ID，详见[会话清理](Session-cleanup.md) |
| 插件更新 API       | 管理协议有更新能力，但插件公开 SDK 未暴露；本插件通过宿主终端和官方 CLI 安装                                                  |
| 外部消息恰好一次   | HTTP 回执可能丢失，平台可能收到重复消息；通用 Webhook 接收端可按事件 ID 去重                                                  |

## 定时任务与权限

任务 ID 来自会话的 `paseo.schedule-id` 标签。任务还没成功创建会话就失败时，不会产生插件能够处理的会话事件。Heartbeat 作用于已有会话，沿用该会话路由。

自动恢复不会回应权限请求、绕过安全策略或处理额度耗尽。AI 复核也不增加这些权限。复核限制通过提供方能力配置实现；不能把它视为独立于提供方的操作系统隔离环境。

## 本插件尚不包含的功能

Bot 回复、Telegram 收消息、小米 / 华为设备推送注册均不在当前范围。通知使用各平台 HTTP 发送接口，无需为插件新增 MCP 连接。
