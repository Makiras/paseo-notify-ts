# 企业微信群机器人

在目标企业微信群中添加群机器人，复制其 Webhook。平台入口和机器人规则见[企业微信官方说明](https://developer.work.weixin.qq.com/document/path/91770)。

| 界面字段    | 填写方法                                                            |
| ----------- | ------------------------------------------------------------------- |
| Webhook URL | `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=<机器人 Key>` |

此地址已经包含发送凭据，无需填写企业 ID、应用 Secret 或单独签名密钥。不同群组分别创建渠道。

插件发送文本消息，按 UTF-8 字节限制截短消息，并检查 `errcode`。限流等可恢复失败按投递策略重试。保存后按[公共步骤](Channels.md)选择路由并测试。

如果返回凭据或权限错误，检查机器人是否已被移除、Key 是否完整、群组类型是否允许机器人。不要把企业应用接口地址填入群机器人渠道。
