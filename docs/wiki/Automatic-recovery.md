# 自动恢复

自动恢复在原会话发送继续指令，让任务从临时中断处继续。它默认关闭，与通知投递重试是两件事。

## 开启与适用异常

进入 Host 插件设置 →「自动恢复」，开启「自动继续」，选择异常类型和预算，点击「保存设置」。

| 中断                                 | 行为                         |
| ------------------------------------ | ---------------------------- |
| 网络故障、连接断开                   | 网络恢复开关启用时重试       |
| 服务繁忙、容量不足、临时服务端错误   | 服务繁忙开关启用时重试       |
| 请求限流                             | 限流开关启用时等待后重试     |
| 额度耗尽、上下文已满                 | 通知人工处理                 |
| 安全策略 / cyber 拦截                | 通知人工处理，不自动反复提交 |
| 未识别错误                           | 停止自动恢复并通知           |
| 用户取消、权限等待、会话或工作区关闭 | 取消后续恢复                 |

三个可恢复类别默认启用，但只有「自动继续」开启后才生效。

## 预算

| 设置             | 默认                       | 用途                                                 |
| ---------------- | -------------------------- | ---------------------------------------------------- |
| 最大重试次数     | 5 次                       | 同一故障恢复计划最多提交几次继续指令                 |
| 恢复时间上限     | 30 分钟                    | 包括等待和复核的总预算                               |
| 初始等待         | 10 秒                      | 第一次恢复前的退避基准                               |
| 两次重试最多间隔 | 300 秒                     | 连续失败时逐渐延长等待；服务要求等得更久时按要求等待 |
| 继续指令         | 检查已有进度，从中断处继续 | 提交给原会话的固定文本                               |

等待逐渐增长并加入少量随机抖动。同一故障预算跨自动轮次和重启保留，重启不会把次数清零。

## 停止条件

提交前会核对原会话可用、空闲、没有待处理权限，并确认用户未接手、内容未变化。无法确认时暂停或取消该计划。发送回执不明确时也会暂停，避免重复提交。

## 取消与通知

在会话恢复卡片点「取消后续重试」，或在 Host「运行状态」点「取消重试」。这只停止后续自动操作，不中止已在运行的 AI 任务；停止当前执行请使用 Paseo 自身的停止操作。

恢复成功发送「恢复后完成」。无法继续或预算耗尽时显示原因，并按渠道选择发送失败或需要处理的通知。
