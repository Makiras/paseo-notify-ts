# 重试前 AI 复核

AI 复核是[自动恢复](Automatic-recovery.md)的可选步骤。每次符合恢复规则的重试前，新建独立审查会话，判断继续、停止或交给用户。

## 开启与配置

先开启「自动继续」，再打开其下方「重试前由 AI 复核」。填写选项后保存。关闭自动恢复后，复核不执行，已有复核设置保留。

| 设置                     | 默认  | 说明                                                                |
| ------------------------ | ----- | ------------------------------------------------------------------- |
| 复核提供方 / 模型        | 留空  | 沿用原会话；也可填写 `codex`、`claude`、`opencode` 或 `提供方/模型` |
| 单次复核超时             | 90 秒 | 超时暂停恢复                                                        |
| 每个恢复计划最多复核次数 | 5 次  | 限制额外审查调用                                                    |
| 会话摘录字符上限         | 8000  | 限制交给审查员的上下文                                              |

使用 Paseo 已配置的模型账户，会产生额外模型调用。复核时间计入原恢复预算，全局最多两个审查员同时运行。

## 交给审查员的信息

包括任务名、故障类别、已重试次数、拟发送的继续指令，以及有限会话消息和工具名称 / 状态摘录。摘录只读取最近一页，不向前寻找用户消息；可能不含最初指令，会明确告知审查员上下文不完整。读取失败时暂停复核并显示具体原因，关闭复核的普通恢复不受历史接口影响。插件不执行审查员返回的命令，也不让它生成新的继续指令。

## 决策影响

| 结果                           | 行为                                         |
| ------------------------------ | -------------------------------------------- |
| 继续                           | 归档审查会话，再次核对原任务，满足条件才继续 |
| 停止 / 需要用户处理            | 暂停恢复，显示理由并通知                     |
| 超时、调用失败、无效答案       | 暂停，不自动重跑审查员                       |
| 原任务被用户接手或恢复配置改变 | 旧结论失效，不继续                           |

安全拦截、额度和上下文耗尽仍按固定规则处理，复核不能解除限制，也不会自动批准权限请求。

## 查看结果

在恢复卡片或「运行状态」查看复核次数、结论与理由。理由不直接附到外部通知。

归档的审查会话仍属于 Paseo 的会话记录。插件不保存完整审查输入。重启时尚未完成的审查会导致恢复暂停，并在取得宿主连接后清理已记录审查员，不自动重新调用 AI。
