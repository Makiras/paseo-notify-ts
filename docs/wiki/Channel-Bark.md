# Bark

在 Bark 客户端取得设备推送地址，也可使用自己的 Bark Server。使用方式见 [Bark 官方教程](https://github.com/Finb/Bark/blob/master/docs/en-us/tutorial.md)。

| 界面字段 | 填写方法                                                 |
| -------- | -------------------------------------------------------- |
| 推送 URL | 带设备 Key 的地址，例如 `https://api.day.app/<设备 Key>` |

保留地址中的设备 Key，不要在后面手工拼入消息标题或正文。插件通过 JSON POST 传入标题和内容，并使用 `Paseo` 分组。

一台设备可以对应一个渠道；多台设备可注册多个渠道并同时选中。插件检查 Bark 的成功状态码，发送失败会显示在运行状态中。

保存后按[公共步骤](Channels.md)选择路由并测试。注意 Host 能访问推送服务与手机允许显示通知是两个独立条件；服务受理成功后，系统通知权限仍由手机控制。
