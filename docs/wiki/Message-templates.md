# 通知消息模板与 Pattern

入口：「设置 → 插件 → Paseo Notifier → 通知与自动恢复 → 通知管理」。页面内提供填写说明、示例按钮和实时预览。

本 Host 所有渠道及通知事件共用这套模板，包括测试通知。修改后点顶部「保存设置」。队列中的通知和重试也使用发送时的设置；已发送的消息不会改变。

## 默认模板

标题：

```text
Paseo · {{event}}
```

正文：

```text
{{title}}
{{summary}}
{{preview}}
{{recovery}}
会话：{{session_id}}
提供方：{{provider}}
{{created_at}}
```

「使用默认模板」重置标题和正文，保留提取规则，保存后生效。标题模板最多 300 字符，正文最多 6000 字符。模板属于普通配置，会随[剪贴板配置](Configuration-transfer.md)导入导出，不应填写 Token 或密码。

## 内置占位符

使用双花括号，例如 `{{title}}`，名称两侧允许空格。页面内「展开字段说明」提供同样的说明。

| 占位符                | 含义                                     |
| --------------------- | ---------------------------------------- |
| `{{event}}`           | 中文事件名称，例如任务完成               |
| `{{event_type}}`      | 事件标识，例如 `completed`               |
| `{{title}}`           | 会话标题                                 |
| `{{summary}}`         | 插件生成的状态说明，不是 AI 回复         |
| `{{preview}}`         | 最终回复摘要，受摘要开关和字符数限制     |
| `{{session_id}}`      | 会话 ID                                  |
| `{{workspace_id}}`    | 工作区 ID，没有时为空；不是目录或名称    |
| `{{schedule_id}}`     | 来源定时任务 ID，普通会话为空            |
| `{{provider}}`        | 提供方，例如 `codex`                     |
| `{{failure}}`         | 异常中文名称，没有异常时为空             |
| `{{failure_type}}`    | 异常标识，例如 `network`，没有时为空     |
| `{{attempts}}`        | 自动恢复尝试次数，没有恢复时为 `0`       |
| `{{recovery}}`        | 有恢复时为“自动恢复尝试：N 次”，否则为空 |
| `{{created_at}}`      | 事件时间，UTC ISO 8601 格式              |
| `{{notification_id}}` | 通知事件 ID                              |

仅含空占位符的行会省略；手写空行和标签保留。例如 `工作区：{{workspace_id}}` 无工作区时仍显示“工作区：”。整段输出为空时，标题回退到默认事件标题，正文回退到状态说明或事件名称。

未知名称、未闭合双花括号会阻止保存。模板只替换一次；回复、捕获值、默认值中的 `{{...}}` 按普通文字发送。不执行脚本、表达式、循环或条件判断。

## 正则提取规则

每条规则提取指定来源中的第一次匹配，通过 `{{custom.变量名}}` 引用。

| 设置项       | 说明                                                                    |
| ------------ | ----------------------------------------------------------------------- |
| 变量名       | 小写字母开头，后续可用小写字母、数字、下划线；最多 32 字符，不能重复    |
| 提取来源     | 最终回复摘要、会话标题、状态说明三选一                                  |
| Pattern      | 直接填写表达式，不加 `/.../`；最多 500 字符                             |
| 捕获组       | `0` 取完整匹配，`1` 取第一个捕获括号，以此类推；组必须存在，最多 20     |
| i            | 忽略大小写                                                              |
| m            | `^` / `$` 匹配每行的开头、结尾                                          |
| s            | `.` 可以匹配换行                                                        |
| 未匹配默认值 | 无输入、无匹配或捕获组未参与匹配时使用；留空表示空字符串，最多 500 字符 |

最多 12 条规则，用「编辑提取规则」下拉菜单切换。变量改名或删除后需同步修改模板引用。支持 [RE2 语法](https://github.com/google/re2/wiki/Syntax)的字符集、分组、分支、重复；不支持前后查找（lookaround）及反向引用。无效或过于复杂的 Pattern 会在保存前提示。

## 示例：工单号

点「添加工单号示例」添加规则，并在正文末尾加入 `工单号：{{custom.ticket}}`。

```text
变量名：ticket
来源：最终回复摘要
Pattern：[A-Z][A-Z0-9]+-[0-9]+
捕获组：0
未匹配默认值：未提供工单号
```

回复 `已处理工单 PROJ-123。` → 正文 `工单号：PROJ-123`。

## 示例：结果链接

点「添加结果链接示例」添加规则和 `结果链接：{{custom.link}}`。

```text
变量名：link
来源：最终回复摘要
Pattern：结果[：:]\s*(https?://[^\s]+)
捕获组：1
标志：i
未匹配默认值：未提供链接
```

回复 `结果：https://example.com/result/123` → 提取 URL。组 `0` 会包含“结果：”，这里用组 `1`。示例要求链接后是空白或文本结尾；若紧接标点，请按实际回复格式调整 Pattern。

重复添加示例会生成新变量名，不覆盖已有规则；示例按钮不自动开启摘要。

## 预览、隐私与测试

预览可修改事件类型、示例标题、状态说明和回复，实时显示匹配结果、最终标题及正文。示例文本仅保留在当前客户端，不保存、不发送、不读取真实会话。

回复提取需要开启同页「附带最终回复摘要」。默认关闭；开启后使用回复前 600 字符，可设 80–2000。关闭时 `{{preview}}` 为空，回复规则使用默认值。超出字符限制的内容不能提取。权限、失败等没有最终回复摘要的事件也使用默认值。

从正文移除 `{{preview}}` 可只显示提取结果；通用 Webhook 的结构化 `preview` 字段仍遵守摘要开关，见[Webhook 协议](Webhook-protocol.md)。

保存后在「通知渠道」点击「发送测试」，向真实目标发送当前模板。测试标题为“Paseo 通知连接测试”，状态说明为“通知渠道已连通。”，不含真实回复摘要。

ntfy / Bark 使用独立标题和正文；其他聊天渠道把标题放在正文第一行。Webhook 的 `text` 合并两者，`message.title` / `message.body` 分别提供渲染结果。渲染标题上限 200 个 UTF-16 单元，正文 16000，之后继续应用平台截断。页面预览不模拟各平台截断。
