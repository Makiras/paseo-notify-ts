# 会话清理与删除

入口：「设置 → 插件 → Paseo Notifier → 会话清理」。也可从「通知管理」的「会话清理」栏目进入，或在命令中心选择「Notifier：会话清理」。

## 删除当前会话

打开聊天输入区的「通知」面板，最底部有红色「删除会话」按钮。

1. 第一次点击只读取会话信息，显示标题、提供方、状态、目录及完整会话 ID。
2. 核对后点击红色「确认删除 1 个会话」，才会执行删除。
3. 点「取消删除」保留会话。成功删除后弹出面板关闭；宿主支持页面导航时，工作区面板入口会返回工作区。

删除立即生效，无需点击「保存设置」。它永久移除 Paseo 会话记录与时间线，无法撤销；运行中的会话会被中断。不会删除项目文件，也不会清除 AI 提供方自己保存的原始历史。

## 选择多个会话

清理页只操作当前 Host，采用按最近更新时间分组的列表，展示标题、提供方、状态、目录与 ID。默认查看「已归档」，也可选择「未归档」或「全部会话」。

- 每次读取 100 条，使用「加载更多会话」继续查看。搜索只覆盖已加载会话，支持标题、目录、提供方和 ID。
- 勾选要删除的会话，每次最多 20 个。「选择当前结果」只选当前显示结果的前 20 个，不会选择尚未加载的会话。
- 更换查看范围、搜索内容、刷新或切换 Host 会清空选择。
- 点击删除后先展示本次清单，二次确认才逐个删除。确认有效期为 5 分钟。
- 成功删除的条目自动移出列表；失败项保留并展示原因，可以刷新核对。关闭页面后不再提交剩余删除，已发出的请求仍可能完成。

如果从「已归档」列表选中的会话在确认期间被其他客户端取消归档，插件会跳过它，要求重新选择。删除过程中读取状态失败也会跳过，不把查询失败当成会话不存在。

## 宿主能力与限制

列表布局参考 Paseo 的历史/归档页，但并非嵌入原生页面。公开插件目录接口会排除部分提供方不可用的旧会话，因此这里只读 Host 已有的 `$PASEO_HOME/agents/` 会话记录，向界面返回标题、目录、状态等必要元数据；不建立额外的会话数据库，也不读取聊天时间线。已禁用或卸载提供方的归档会话仍会显示。内部临时记录不展示；损坏、超过 16 MiB 或无法读取的记录会计数提示，避免把不完整列表当成已经清空。

插件通过 Host 上的 Paseo CLI 删除已确认的完整会话 ID，明确指定当前 Host 数据目录，不使用批量删除参数、不手动删除会话文件。Host 没有可执行 CLI 时仍可查看列表，删除不可用；当前自动定位不支持 Windows 的 `.cmd` 启动器。

删除前会停止本插件为该会话安排的自动恢复；命令返回后再次查询会话是否消失。连接中断或结果不明时不会自动重发，请刷新列表检查。确认清单短暂保存在内存中，不建立会话数据库。

删除成功后会清理该会话的通知绑定和自动继续配置，其他范围和已注册渠道保持原样。若出现「配置待清理」，点击「重试清理」；这一步只保存配置，不会再次删除会话。通过 Paseo 其他入口删除、或删除时客户端断开，可能留下少量绑定，详见[删除后的配置](Storage-and-reliability.md#删除后的配置)。
