# 通用 Webhook

用于自建通知服务、自动化平台或其他接受 JSON POST 的接收端。插件直接发送请求，不启动 HTTP 服务。

| 界面字段          | 填写方法                                                         |
| ----------------- | ---------------------------------------------------------------- |
| Webhook URL       | 完整的 HTTP(S) 接收地址，例如 `https://notify.example.com/paseo` |
| 签名密钥          | 可选，与接收端约定的 HMAC 密钥                                   |
| Bearer Token      | 可选，只填 Token 本身                                            |
| 自定义请求头 JSON | 可选，例如 `{"X-Team":"engineering"}`                            |

接收端应在成功受理后返回 HTTP 2xx。非 2xx 会按状态码决定重试；这里不检查响应 JSON 的业务字段。请求不跟随重定向，请填写最终地址。

请求体包括事件 ID、会话、工作区、任务 ID、事件类型、摘要以及可读文本。签名基于时间戳和原始请求体；接入实现见 [Webhook 协议](Webhook-protocol.md)。自定义请求头不能覆盖插件的签名、幂等或 HTTP 传输控制字段。

保存后执行[渠道配置的公共步骤](Channels.md)。常见问题是接收地址返回登录页、重定向或服务只支持表单；这里发送的是 `application/json`。
