# 飞书 / Lark 群机器人

在接收群添加自定义机器人，复制机器人的 Webhook；如果开启了签名校验，同时取得签名密钥。具体入口以[飞书自定义机器人说明](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)为准。

## 填写连接信息

| 界面字段         | 填写方法                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------ |
| Webhook 地址     | `https://open.feishu.cn/open-apis/bot/v2/hook/<机器人 ID>`；Lark 使用 `open.larksuite.com` |
| 签名密钥（可选） | 开启机器人签名时填写，否则留空                                                             |

这里使用自定义群机器人，无需应用机器人的 App ID / App Secret。

## 选择消息类型

打开「通知渠道」，在「编辑渠道」中选中飞书渠道，名称下方有「消息类型」下拉菜单：

| 类型             | 接收效果                                 |
| ---------------- | ---------------------------------------- |
| 文本消息（默认） | 标题在第一行，正文接在下面               |
| 卡片消息         | 标题放在彩色标题栏，正文显示在卡片内容区 |

例如“开发群”选择卡片，“值班群”保留文本。同一个会话同时选择这两个渠道，就会分别按各自的格式发送。工作区、会话和定时任务只决定发送到哪个渠道，消息类型跟随所选渠道。

切换类型不需要重填 Webhook 或密钥。已有渠道升级后仍使用文本。点击顶部「保存设置」，再点击「发送测试」，测试会使用已保存的消息类型和模板。

## 卡片内容与预览

卡片复用「通知管理」中的标题、正文、占位符和 Pattern 提取规则。例如标题 `Paseo · {{event}}`，正文 `任务：{{title}}\n工单：{{custom.ticket}}`（在正文输入框中实际换行）。内置卡片无需创建飞书模板或填写 JSON。

选择卡片后显示「卡片示例」。可以切换示例通知类型：完成或恢复后完成为绿色，失败为红色，需要处理或等待权限为橙色，测试通知为蓝色。预览使用当前模板草稿和内置示例任务，不读取真实会话，也不会发送消息。它展示相同的最终文字及截断结果，具体字体、间距以飞书客户端为准。

正文按普通文字显示，Markdown 符号不会变成加粗或按钮。消息里的 `<at` 会被处理，避免任务内容意外提醒群成员。回复摘要及从摘要中提取的变量都遵守「附带最终回复摘要」开关和字符数限制。过长内容以省略号结尾；完整发送请求保留在飞书的 20 KB 限制以内。

## 保存与排查

添加渠道后，还需在 Host 默认、工作区、会话或定时任务中选择它，才会自动接收通知。「发送测试」可直接测试当前渠道，无需先选为默认。

收不到消息时先核对完整地址、签名配置以及机器人允许的关键词或来源策略。插件会检查平台业务返回码；卡片失败时不会自动补发文本，以免重复通知。
