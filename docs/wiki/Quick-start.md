# 快速上手

目标是让第一个会话完成后发出通知。安装步骤见[安装与更新](Installation-and-updates.md)。

## 注册接收目标

1. 打开「设置 → 插件 → Paseo Notifier → 通知管理」。
2. 在「通知渠道」栏目选择「新渠道平台」，例如飞书或 Telegram，再点「添加渠道」。
3. 给渠道起一个接收目标名称，例如「开发群」或「我的手机」。
4. 按[对应平台说明](Channels.md)填写地址、Token、群组或话题。
5. 在「Host 默认通知渠道」中勾选此渠道。
6. 点击顶部「保存设置」：先保存渠道定义，再保存已填写的凭据。

一个渠道代表一个具体接收目标。向两个群组发送时，注册两个渠道并同时勾选。注册渠道本身不会自动把它加入 Host 默认选择。

## 验证连接与实际通知

点击渠道下的「发送测试」，确认收到测试消息。随后在 Paseo 中完成一个普通会话轮次，确认收到任务完成通知。

测试按钮直接向选定渠道发送，用于验证凭据和连接。它不验证会话继承、事件或工作区过滤；出现「测试成功但任务没有通知」时，按[排错说明](Activity-and-troubleshooting.md)检查实际去向。

## 根据需要调整

| 需要                   | 操作                                           |
| ---------------------- | ---------------------------------------------- |
| 某个会话发到另一个群   | 输入区「通知」中关闭「跟随上级」，选择渠道     |
| 整个工作区使用同一个群 | 会话「通知」→「工作区通知设置」→「打开」       |
| 定时任务永久发到固定群 | Host 设置的「定时任务」栏目中绑定              |
| 临时网络故障后自动继续 | 打开「自动恢复与继续」，开启「自动继续」并保存 |
| 继续前让 AI 判断       | 在自动恢复下启用「重试前由 AI 复核」           |
| 通知附上最终回复片段   | 开启「通知管理 → 附带最终回复摘要」            |

新安装默认不选通知渠道，自动恢复、AI 复核、回复摘要和「包含子代理」默认关闭。
